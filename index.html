好友名單

好友名稱會顯示在花種紀錄中。同一種花可以同時收藏於多位好友名下，只有管理員可以修改。

雲端連線設定

建立 Supabase 專案後，填入 Project URL 與 anon/public key。這兩項可放在前端；絕不可填入 service_role key。

連線設定只儲存在目前瀏覽器。若要讓每位好友使用同一個網站，請將這兩項寫入網站部署環境或由管理者完成設定。

資料庫初始化

請在 Supabase → SQL Editor 執行隨附的 upgrade_simple.sql，再依說明綁定好友帳號。

此版本公開讀取，只有管理員可以修改資料。複選好友功能請先執行隨附的 SQL。
